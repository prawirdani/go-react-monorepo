# AGENTS.md

## Architecture

```
pnpm v10.28.1 workspace monorepo with Turborepo
apps/dashboard/     -- Vite + TanStack Router app (port 3000)
packages/
  config/           -- shared tsconfig.base.json (@repo/config)
  utils/            -- date, string, formatter helpers (@repo/utils)
  schemas/          -- Zod v4 schemas; exports: ./auth, ./user
  api/              -- HTTP client, auth API, response helpers (@repo/api)
  queries/          -- TanStack Query hooks (@repo/queries)
  ui/               -- shadcn/ui (Base UI + Tailwind v4) (@repo/ui)
```

Build order: config → utils → schemas → api → queries → ui → dashboard.

Tests live only in `apps/dashboard/` (Vitest):
```bash
pnpm --filter=dashboard test
pnpm --filter=dashboard vitest run
```

Commands run from root via Turbo (`pnpm dev`, `pnpm build`, `pnpm lint`, etc.) or per-package with `--filter`.

## Backend API (golang-restapi)

The dashboard communicates with a Go API (`github.com/prawirdani/golang-restapi`) running on `VITE_API_URL` (default `localhost:8080`). All routes are under `/api`.

### Auth Endpoints

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/auth/login` | No | Login via email+password |
| `POST` | `/api/auth/refresh` | No | Rotate refresh token |
| `DELETE` | `/api/auth/logout` | Yes | Revoke session |
| `GET` | `/api/auth/me` | Yes | Get current user profile |
| `POST` | `/api/auth/register` | No | Register new user |
| `POST` | `/api/auth/password/change` | Yes | Change password |
| `POST` | `/api/auth/password/recover` | No | Request password reset |
| `GET` | `/api/auth/password/recover/{token}` | No | Validate recovery token |
| `POST` | `/api/auth/password/reset` | No | Complete password reset |

### User Endpoints

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/users/profile/upload` | Yes | Upload profile picture (multipart, max 2MB) |

### Auth Flow

- **Split-token design**: JWT access token (HS256, 60m TTL) + opaque refresh token (SHA-256 hashed, 7d TTL).
- **Token delivery**: Both cookies (`HttpOnly`, `Secure`, `SameSite=Lax`) OR `Authorization: Bearer` header.
- **Refresh rotation**: Each refresh invalidates the old refresh token and issues a new one (replay protection).
- **Logout**: Revokes session server-side, clears cookies.

### Error Format

All errors return:
```json
{ "error": { "message": "string", "code": "STRING_CODE", "details": {} | null } }
```

| Code | HTTP | Meaning |
|---|---|---|
| `AUTH_CREDENTIALS` | 401 | Wrong email/password |
| `AUTH_EXPIRED` | 401 | Access token expired |
| `AUTH_INVALID_SESSION` | 401 | Session expired/revoked |
| `REQ_UNAUTHORIZED` | 401 | Missing/invalid access token |
| `VALIDATION` | 422 | Request body validation failed |
| `USER_EMAIL_CONFLICT` | 409 | Email already registered |
| `RESOURCE_NOT_FOUND` | 404 | Resource not found |

### Response Format

Success responses:
```json
{ "data": { ... }, "message": "string | null" }
```

### Login response

```json
{ "data": { "access_token": "string", "refresh_token": "string" }, "message": null }
```
Cookies also set with both tokens.

### Current user (`GET /api/auth/me`)

```json
{ "data": { "id": "uuid", "name": "string", "email": "string", "phone": "string | null", "profile_image": "string | null", "created_at": "ISO8601", "updated_at": "ISO8601" }, "message": null }
```

### Image URL

`VITE_IMAGE_URL` prefixes user profile images (e.g., `https://cdn.example.com/profiles/abc.jpg`).

## TanStack Form (Reusable Form System)

**`@tanstack/react-form`** with `createFormHook` (`@/components/form/hooks.tsx`). The custom `useAppForm` registers shared field and form components so they're available via `form.AppField` / `form.AppForm`.

**Available field components** (via `field.Container`, `field.Label`, `field.TextField`, etc.):
- `Container` — wraps field with validation state
- `Label` — auto-linked via `htmlFor={field.name}`, supports `required` indicator
- `TextField`, `TextAreaField`, `PriceField`, `FileField`, `SwitchToggle`, `Select`, `ComboboxChips`, `Errors`

**Available form components** (via `form.Root`, `form.SubmitButton`, `form.Blocker`):
- `Root` — `<form>` wrapper, calls `form.handleSubmit()` on submit
- `SubmitButton` — disabled while submitting or invalid, shows loading spinner
- `Blocker` — intercepts navigation when form is dirty via `useBlocker` from TanStack Router

**Usage pattern** (from `login.tsx`):
```tsx
const form = useAppForm({
  defaultValues: { email: "", password: "" },
  validators: { onSubmit: loginSchema },  // Zod schema from @repo/schemas
  onSubmit: async ({ value }) => {
    try {
      await authActions.login(value)
      router.invalidate()
      router.navigate({ to: search.redirect || "/", replace: true })
    } catch (error) {
      handleError(error, (apiErr) => {
        if (apiErr.code === "AUTH_CREDENTIALS") {
          setRootError("Email atau kata sandi Anda salah")
          return true  // handled, skip toast fallback
        }
        return false  // unhandled, useErrorHandler shows toast
      })
    }
  },
})

return (
  <form.AppForm>
    <form.Root className="flex-1 flex flex-col gap-8">
      <FieldGroup className="flex-1">
        <form.AppField name="email" children={(field) => (
          <field.Container>
            <field.Label text="Email" required />
            <field.TextField placeholder="Masukan alamat email Anda" autoComplete="on" />
            <field.Errors />
          </field.Container>
        )} />
        <form.AppField name="password" children={(field) => (
          <field.Container>
            <field.Label text="Kata Sandi" required />
            <field.TextField placeholder="Masukan kata sandi Anda" type="password" autoComplete="on" />
            <field.Errors />
          </field.Container>
        )} />
      </FieldGroup>

      {rootError && (
        <div className="outline outline-destructive rounded-sm p-2 flex gap-2 items-center bg-destructive/2">
          <AlertTriangle className="text-destructive" />
          <span className="text-destructive">{rootError}</span>
        </div>
      )}

      <form.SubmitButton className="w-full" text="Masuk" />
    </form.Root>
  </form.AppForm>
)
```

Key points from the pattern:
1. **Wrap in `<form.AppForm>`** — provides the form context to all children.
2. **`<form.Root>` renders the `<form>` tag** — calls `form.handleSubmit()` on submit; do not use a raw `<form>`.
3. **`<form.AppField name="..." children={(field) => ...} />`** — the child receives typed field helpers (`field.Container`, `field.Label`, etc.).
4. **Always nest field components inside `<field.Container>`** — it wires validation state and `aria-invalid`.
5. **`<field.Label text="..." required />`** — auto-links `htmlFor={field.name}`; add `required` to show a red `*` indicator.
6. **`<field.Errors />`** — renders inline validation errors from the schema; only shows when the field is touched and has errors.
7. **`<form.SubmitButton text="..." />`** — auto-disables while submitting or invalid; shows a loading spinner.
8. **Root-level errors** — maintain a `rootError` state for non-field errors (e.g. wrong credentials); render it manually above the submit button.
9. **Group fields with `<FieldGroup>`** from `@repo/ui/components/field` for layout control.

**Error handling utilities** (`@/components/form/utils.ts`):
- `setFormErrors(formApi, error)` — maps single `{ field, message }` or `Record<field, { message }>` errors back to form fields
- `buildErrorMap(details)` — transforms `ErrValidation<T>["details"]` (from `@repo/api/errors`) into TanStack Form field errors
- `isFieldInvalid(field)` — checks `isTouched && errors.length > 0`

**API error pattern** (from `login.tsx`):
- Import `useErrorHandler` from `@/hooks/use-error-handler`
- Call `handleError(error, override?)` in the catch block
- The override receives a parsed `APIError`; return `true` to suppress the default toast fallback
- Unhandled errors (`return false`) automatically show a toast via `useErrorHandler`
- Auth expiry/unauthorized errors (`REQ_UNAUTHORIZED`, `AUTH_EXPIRED`, `AUTH_INVALID_SESSION`) are auto-handled: they trigger session expiry and redirect to login. No override needed.
